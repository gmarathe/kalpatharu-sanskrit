# ಕಲ್ಪತರು ಸಂಸ್ಕೃತ ಮಂಡಲಮ್ · Kalpatharu Sanskrit Circle

पठामः • वदामः • प्रसारयामः

ಕನ್ನಡದ ಮೂಲಕ ಸಂಸ್ಕೃತ ಕಲಿಯುವ ಆ್ಯಪ್ (PWA). ಸರ್ವರ್ ಕೋಡ್ ಇಲ್ಲ — Cloudflare Worker ನ ಸ್ಟ್ಯಾಟಿಕ್ ಫೈಲ್‌ಗಳಾಗಿ ನಡೆಯುತ್ತದೆ.

## ಫೋಲ್ಡರ್‌ಗಳು

| ಫೈಲ್ | ಏನು |
|---|---|
| `src/content.js` | **ಎಲ್ಲಾ ಪಾಠದ ವಿಷಯ** — ಪದ, ವಾಕ್ಯ, ಸಂವಾದ, ಸವಾಲುಗಳು. ವಿಷಯ ತಿದ್ದಲು ಇದೊಂದೇ ಫೈಲ್ ಸಾಕು. |
| `src/lib.js` | ಪ್ರಗತಿ ಉಳಿಕೆ, ಪುನರಾವರ್ತನಾ ಎಂಜಿನ್, ಹಂಚಿಕೆಯ ಸಂದೇಶಗಳು, ಸೆಟ್ಟಿಂಗ್‌ಗಳು (`APP_URL`, ವಾಟ್ಸಾಪ್ ಲಿಂಕ್) |
| `src/app.jsx`, `src/ui.jsx` | ಪರದೆಗಳು ಮತ್ತು ಪ್ರಶ್ನೆಗಳು |
| `src/style.css` | ವಿನ್ಯಾಸ (ಹೈ-ಕಾಂಟ್ರಾಸ್ಟ್ ಸೇರಿ) |
| `public/` | ಪ್ರಕಟವಾಗುವ ಫೈಲ್‌ಗಳು (`npm run build` ತಯಾರಿಸುತ್ತದೆ) |
| `CONTENT_REVIEW.md` | ಪುಸ್ತಕದೊಂದಿಗೆ ಹೋಲಿಸಲು ಪರಿಶೀಲನಾ ಪಟ್ಟಿ |

## ವಿಷಯ ತಿದ್ದುವುದು

1. `src/content.js` ನಲ್ಲಿ ಬೇಕಾದ ಸಾಲನ್ನು ತಿದ್ದಿ. **`id` ಬದಲಿಸಬೇಡಿ** — ಕಲಿಯುವವರ ಪ್ರಗತಿ id ಗೆ ಕಟ್ಟಿದೆ.
2. ಪುಸ್ತಕದೊಂದಿಗೆ ಹೋಲಿಸಿದ ಮೇಲೆ: `status: "VERIFIED"`, `src: "ಪುಸ್ತಕ, ಪಾಠ #"`, `reviewedBy`, `reviewedOn`.
3. ತಪ್ಪು ಖಚಿತವಾದರೆ `status: "WITHDRAWN"` — ಎಲ್ಲರಿಗೂ ತಕ್ಷಣ ಮರೆಯಾಗುತ್ತದೆ.
4. ಅರ್ಥ ಬರೆಯುವ ನಿಯಮ: ಸಂಸ್ಕೃತದಲ್ಲಿ ಇಲ್ಲದ ಪದವನ್ನು ಅರ್ಥದಲ್ಲಿ ಸೇರಿಸಬೇಡಿ. `पठामि` = ಓದುತ್ತೇನೆ; `अहं पठामि` = ನಾನು ಓದುತ್ತೇನೆ.

## ಪ್ರಕಟಿಸುವುದು (Cloudflare)

ಒಮ್ಮೆ ಮಾತ್ರ: Cloudflare → Workers & Pages → Create → Import a repository → ಈ repo ಆರಿಸಿ.

- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`

ನಂತರ ಪ್ರತಿ ಬಾರಿ `main` ಗೆ ಬದಲಾವಣೆ ಬಂದಾಗ ತಾನಾಗಿ ಪ್ರಕಟವಾಗುತ್ತದೆ.

ಡೊಮೈನ್: Worker → Settings → Domains & Routes → Add → Custom domain → `ksm.kalpatharu.org`.
ಬೇರೆ ವಿಳಾಸ ಬಳಸಿದರೆ `src/lib.js` ನಲ್ಲಿ `APP_URL` ಬದಲಿಸಿ.

ಸ್ಥಳೀಯವಾಗಿ: `npm install && npm run build`, ನಂತರ `npx wrangler dev`.

## ಹಳೆಯ Netlify ಸೈಟ್‌ನಿಂದ ವರ್ಗಾವಣೆ

ಪ್ರಗತಿ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ವೆಬ್ ವಿಳಾಸಕ್ಕೆ ಕಟ್ಟಿಕೊಂಡಿರುತ್ತದೆ. ಹಳೆಯ ಕಲಿಯುವವರ ಪ್ರಗತಿ ಉಳಿಸಲು:

1. ಈ `public/` ಫೋಲ್ಡರ್ ಅನ್ನು **ಕೊನೆಯ ಬಾರಿ** Netlify ಗೆ ಹಾಕಿ (ಅದೇ ಉಳಿಕೆಯ ಕೀ, ಹಾಗಾಗಿ ಹಳೆಯ ಪ್ರಗತಿ ಉಳಿಯುತ್ತದೆ).
2. ಕಲಿಯುವವರು "ನಾನು → ಪ್ರಗತಿಯ ಬ್ಯಾಕಪ್ → ವಾಟ್ಸಾಪ್‌ಗೆ ಕಳಿಸಿ" ಒತ್ತುತ್ತಾರೆ.
3. ಆ ಲಿಂಕ್ ಒತ್ತಿದರೆ ಹೊಸ ವಿಳಾಸದಲ್ಲಿ ಪ್ರಗತಿ ಸೇರುತ್ತದೆ.

## ಆವೃತ್ತಿ 2.6 ರಲ್ಲಿ ಏನು ಬದಲಾಯಿತು (ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ — ಹಂತ 2)

- **ಡ್ಯಾಶ್‌ಬೋರ್ಡ್: `ksm.kalpatharu.org/admin`.** `wrangler.jsonc` → `vars.ADMIN_EMAILS` ನಲ್ಲಿರುವ Google ಖಾತೆಗಳಿಗೆ ಮಾತ್ರ ತೆರೆಯುತ್ತದೆ (ಆ್ಯಪ್‌ನಲ್ಲಿ ಮೊದಲು ಲಾಗಿನ್ ಆಗಿರಬೇಕು).
- ಮೇಲೆ ಸಂಖ್ಯೆಗಳು: ಒಟ್ಟು ಸದಸ್ಯರು, ಇಂದು ಕಲಿತವರು, ಕಳೆದ 7 ದಿನ ಸಕ್ರಿಯ, 7 ದಿನದಿಂದ ನಿಂತವರು, ಸತತ 7 ದಿನ, ಮೊಬೈಲ್ ಸಂಖ್ಯೆ ಕೊಟ್ಟವರು.
- ಸದಸ್ಯರ ಪಟ್ಟಿ: ಹೆಸರು, ಇಮೇಲ್, ಮೊಬೈಲ್ (ಒತ್ತಿದರೆ ವಾಟ್ಸಾಪ್), ಈ ವಾರದ ಸಾಧನಾ ಅಂಕ (200 ರಲ್ಲಿ), ಕಲಿತ ದಿನಗಳು, ಪದ/ವಾಕ್ಯ/ಇತರ, ಸರಣಿ, ಕೊನೆಯ ಚಟುವಟಿಕೆ. ಫಿಲ್ಟರ್, ಹುಡುಕಾಟ, ಕ್ರಮ, ಹಿಂದಿನ ವಾರಗಳು, CSV ಡೌನ್‌ಲೋಡ್.
- ಸಾಧನಾ ಅಂಕ (ವಾರಕ್ಕೆ ಗರಿಷ್ಠ 200): ಕಲಿತ ದಿನ 10 · ಇಂದಿನ ಯೋಜನೆ ಪೂರ್ಣ 5 · ಹೊಸ ಐಟಂ 1 (ದಿನಕ್ಕೆ ಗರಿಷ್ಠ 10) · ಸವಾಲಿನ ಪ್ರತಿ ಹೆಜ್ಜೆ 5 + ಮೂರೂ ಆದರೆ 10. ವಾರ ಸೋಮವಾರದಿಂದ (ಭಾರತೀಯ ಸಮಯ).
- ಸರ್ವರ್: ಪ್ರತಿ ಸಿಂಕ್‌ನಲ್ಲಿ `progress` ಕೋಷ್ಟಕದಲ್ಲಿ ಸಾರಾಂಶ ಉಳಿಯುತ್ತದೆ; ಪರಿಶೀಲಿತ (verified) Google ಇಮೇಲ್ ಮಾತ್ರ ಉಳಿಸಲಾಗುತ್ತದೆ.

## ಆವೃತ್ತಿ 2.5 ರಲ್ಲಿ ಏನು ಬದಲಾಯಿತು (ಕ್ಲೌಡ್ ಉಳಿಕೆ — ಹಂತ 1)

- **Google ಲಾಗಿನ್ + ಕ್ಲೌಡ್ ಉಳಿಕೆ.** "ನಾನು" ಪರದೆಯಲ್ಲಿ ಹೊಸ "ಕ್ಲೌಡ್ ಉಳಿಕೆ" ಕಾರ್ಡ್. ಲಾಗಿನ್ ಆದ ಮೇಲೆ ಪ್ರಗತಿ ತಾನಾಗಿ ಸರ್ವರ್‌ಗೆ ಉಳಿಯುತ್ತದೆ (ಬದಲಾವಣೆಯ 4 ಸೆಕೆಂಡ್ ನಂತರ, ಮತ್ತು ಆ್ಯಪ್ ಮುಚ್ಚುವಾಗ). ಹೊಸ ಫೋನಿನಲ್ಲಿ ಅದೇ ಖಾತೆಯಿಂದ ಲಾಗಿನ್ ಆದರೆ ಪ್ರಗತಿ ಮರಳಿ ಬರುತ್ತದೆ. ಲಾಗಿನ್ ಇಲ್ಲದೆಯೂ ಆ್ಯಪ್ ಮೊದಲಿನಂತೆಯೇ ನಡೆಯುತ್ತದೆ.
- **ಮೊಬೈಲ್ ಸಂಖ್ಯೆ** ಮೊದಲ ಲಾಗಿನ್ ನಂತರ, "ತಂಡದ ಸಂಪರ್ಕಕ್ಕೆ ಮಾತ್ರ" ಒಪ್ಪಿಗೆಯೊಂದಿಗೆ. ವಾರದ ಸಾಧಕರ ಪಟ್ಟಿಯಲ್ಲಿ ಹೆಸರು ತೋರಿಸುವುದು ಸದಸ್ಯರ ಆಯ್ಕೆ (ಡೀಫಾಲ್ಟ್: ಇಲ್ಲ).
- **ದಿನದ ಚಟುವಟಿಕೆ ದಾಖಲೆ** (`log`): ಪ್ರತಿ ದಿನ ಎಷ್ಟು ಹೊಸ ಐಟಂ, ಇಂದಿನ ಯೋಜನೆ ಪೂರ್ಣವೇ. ವಾರದ ಅಂಕಗಳಿಗೆ (ಹಂತ 3) ಇದೇ ಆಧಾರ.
- **ಸರ್ವರ್:** `src/worker.js` (`/api/*` ಮಾತ್ರ), D1 ಡೇಟಾಬೇಸ್ `kalpatharu-sanskrit` (ಮೊದಲ deploy ನಲ್ಲಿ ತಾನಾಗಿ ಸೃಷ್ಟಿ; ಕೋಷ್ಟಕಗಳು ಮೊದಲ ಕರೆಯಲ್ಲಿ). ವಿಲೀನ ನಿಯಮ `src/merge.js` — ಆ್ಯಪ್ ಮತ್ತು ಸರ್ವರ್ ಎರಡೂ ಇದನ್ನೇ ಬಳಸುತ್ತವೆ.
- **Google Client ID** `wrangler.jsonc` → `vars.GOOGLE_CLIENT_ID`. ಖಾಲಿ ಇದ್ದರೆ ಲಾಗಿನ್ ಕಾರ್ಡ್ ಕಾಣಿಸುವುದಿಲ್ಲ.

## ಆವೃತ್ತಿ 2.4 ರಲ್ಲಿ ಏನು ಬದಲಾಯಿತು (ವಿಷಯ ವಿಸ್ತರಣೆ)

- **ಪದಗಳು 107 → 209.** ಹೊಸ ಘಟಕ 11–17: ಬಣ್ಣ ಮತ್ತು ಗುಣ, ಇನ್ನಷ್ಟು ಕ್ರಿಯಾಪದ, ಪ್ರಾಣಿ–ಪಕ್ಷಿ, ವಾರ ಮತ್ತು ಸಮಯ, ಊರಿನ ಸ್ಥಳಗಳು, ಅವ್ಯಯ ಮತ್ತು ಸ್ಥಾನ, ಸಂಖ್ಯೆ 11–20 ಮತ್ತು ಕ್ರಮವಾಚಕ. ಘಟಕ 10 ಕ್ಕೆ ಪದಗಳು (ಮೊದಲು ವಾಕ್ಯ ಮಾತ್ರ ಇದ್ದವು).
- **ವಾಕ್ಯಗಳು 52 → 98** (ಹೊಸ ಘಟಕಗಳಿಗೆ, ಘಟಕ 8 ಮತ್ತು 10 ಕ್ಕೂ), ಎಲ್ಲಕ್ಕೂ ಪದಚ್ಛೇದ.
- **ಸಂವಾದ 5 → 10:** ಅಂಗಡಿ, ಶಾಲೆ, ದೂರವಾಣಿ, ಅತಿಥಿ, ವೈದ್ಯರ ಬಳಿ.
- **ವ್ಯಾಕರಣ 10 → 14:** ಭೂತಕಾಲ, ಭವಿಷ್ಯತ್ಕಾಲ, ತೃತೀಯಾ–ಚತುರ್ಥೀ–ಪಂಚಮೀ, ವಿಶೇಷಣ ಹೊಂದಾಣಿಕೆ.
- **ಸುಭಾಷಿತ 12 → 24:** ಭಗವದ್ಗೀತೆಯ 4 (2.47, 2.48, 4.39, 6.5) ಮತ್ತು ನೀತಿಶ್ಲೋಕ 8.
- **ವಾಚನ 7 → 12:** ಅಂಗಡಿ, ದೀಪಾವಳಿ, ಕಾಗೆ ಮತ್ತು ಹೂಜಿ, ನನ್ನ ಹಳ್ಳಿ, ಸಂಸ್ಕೃತ ಮಂಡಲ. ಸಪ್ತಾಹದ ಸವಾಲು 14 → 20.
- **ತುಂಬಿದ ಖಾಲಿ ಜಾಗಗಳು:** ಅಭ್ಯಾಸ ಟ್ಯಾಬ್‌ನಲ್ಲಿ ವ್ಯಾಕರಣ ಅಭ್ಯಾಸ (ಮುಗಿಸಿದ ಪಾಠಗಳಿಂದ 8 ಪ್ರಶ್ನೆ); ಶಬ್ದಕೋಶದಲ್ಲಿ ವಾಚನದ ಹೊಸ ಪದಗಳೂ ಸಿಗುತ್ತವೆ; "ಸಂಸ್ಕೃತಸಾಧಕಃ" ಗುರಿ ಈಗ ನಿಜವಾದ ಸಾಧನೆ (ಆರೂ ಹಂತ ಪೂರ್ಣ) ಮತ್ತು ಕಲಿಕೆಯ ಪಥದಲ್ಲಿ ಅದರ ಪ್ರಗತಿ; "ದ್ವಿಶತಪದಾನಿ" (200 ಪದ) ಸಾಧನೆ.
- ಎಲ್ಲಾ ಹೊಸ ವಿಷಯ `REVIEW_REQUIRED`; `CONTENT_REVIEW.md` ನಲ್ಲಿ ಹೊಸ ಪದ, ವಾಕ್ಯ, ಸಂವಾದ, ಪಾಠ, ಶ್ಲೋಕ, ವಾಚನಗಳ ಪರಿಶೀಲನಾ ಪಟ್ಟಿ.

## ಆವೃತ್ತಿ 2.3 ರಲ್ಲಿ ಏನು ಬದಲಾಯಿತು

- **ಬಾಕಿ ಇರುವ ಸಾಧನೆಗಳು ಈಗ ಜೀವಂತ** ("ನಾನು" ಟ್ಯಾಬ್): ಪ್ರತಿ ಬಾಕಿ ಸಾಧನೆಯ ಕಾರ್ಡ್‌ನಲ್ಲಿ ಪ್ರಗತಿ ಪಟ್ಟಿ ಮತ್ತು ಎಣಿಕೆ (ಉದಾ: 12 / 50), ಹಾಗೂ ಅದನ್ನು ಪಡೆಯುವ ದಾರಿಯ ಸೂಚನೆ. ಕಾರ್ಡ್ ಒತ್ತಿದರೆ ನೇರವಾಗಿ ಆ ಪಾಠಕ್ಕೆ (ಪದಗಳ ಪಾಠ / ವಾಕ್ಯ / ಸಂವಾದ / ವ್ಯಾಕರಣ / ಸುಭಾಷಿತ / ವಾಚನ) ಅಥವಾ ಮನೆ ಪುಟಕ್ಕೆ (ಸರಣಿ, ಸಪ್ತಾಹದ ಸವಾಲು) ಹೋಗುತ್ತದೆ. ಪಡೆದ ಸಾಧನೆ ಒತ್ತಿದರೆ ಮೊದಲಿನಂತೆ ಹಂಚಿಕೊಳ್ಳಬಹುದು. `BADGES` ನಲ್ಲಿ ಪ್ರತಿ ಸಾಧನೆಗೆ `p` (ಪ್ರಗತಿ), `go` (ಎಲ್ಲಿಗೆ), `h` (ಸೂಚನೆ) ಸೇರಿದೆ.
- ಸಾಧನೆಗಳ ತಲೆಬರಹದಲ್ಲಿ ಎಣಿಕೆ (ಉದಾ: 4 / 13).

## ಆವೃತ್ತಿ 2.2 ರಲ್ಲಿ ಏನು ಬದಲಾಯಿತು (ಹಂತ-1 ಸುಧಾರಣೆ)

- **ಇಂದಿನ ಯೋಜನೆ** ಮನೆ ಪುಟದಲ್ಲಿ: ಹೊಸ ಪದಗಳ ಪಾಠ · ಒಂದು ವಾಕ್ಯ · ಪುನರಾವರ್ತನೆ · ಇಂದಿನ ಸುಭಾಷಿತ — ನಾಲ್ಕು ಗುರುತುಗಳು, ದಿನಕ್ಕೊಮ್ಮೆ ಮರುಹೊಂದಿಕೆ. ಎಲ್ಲಾ ಮುಗಿದಾಗ ಸಂದೇಶ. (`plan` ಸ್ಥಿತಿ, ಬ್ಯಾಕಪ್‌ನಲ್ಲೂ ಸೇರುತ್ತದೆ.)
- **ಪುನರಾವರ್ತನೆ ಎಂಜಿನ್ ಈಗ ಎಲ್ಲಾ ಹಂತಗಳಿಗೂ**: ವ್ಯಾಕರಣ (`g<id>`), ಸುಭಾಷಿತ (`u<id>`), ವಾಚನ (`r<id>`) ಕೂಡ ಕಲಿತ ಮರುದಿನದಿಂದ ಪುನರಾವರ್ತನೆಗೆ ಬರುತ್ತವೆ; ತಪ್ಪುಗಳ ಪುಸ್ತಕದಲ್ಲೂ ಸೇರುತ್ತವೆ.
- **ವ್ಯಾಕರಣ ಪ್ರಶ್ನೆಗಳು ಕೋಷ್ಟಕದಿಂದ ತಾನಾಗಿ**: ಉದಾಹರಣೆ ವಾಕ್ಯದ ಒಂದು ರೂಪ ಖಾಲಿ ಬಿಟ್ಟು, ಅದೇ ಧಾತು / ಅದೇ ಪಾಠದ ರೂಪಗಳನ್ನು ಆಯ್ಕೆಗಳಾಗಿ ಕೊಡುತ್ತದೆ. ಪ್ರತಿ ಅಭ್ಯಾಸಕ್ಕೆ 6 ಪ್ರಶ್ನೆ (ಬರೆದವು + ತಾನಾಗಿ ಬಂದವು).
- **ತಪ್ಪಾದಾಗ ವಿವರಣೆ**: ಪದ (ಅರ್ಥ + ಟಿಪ್ಪಣಿ), ವಾಕ್ಯ (ಪದಚ್ಛೇದ), ವ್ಯಾಕರಣ (ಸರಿ ರೂಪ + ನಿಯಮ), ಸುಭಾಷಿತ (ಪೂರ್ಣ ಸಾಲು + ಅರ್ಥ), ಸಂವಾದ (ಮುಂದಿನ ಸಾಲಿನ ಅರ್ಥ).
- **ದಿನನಿತ್ಯದ ನೆನಪು** ("ನಾನು" ಟ್ಯಾಬ್): ಫೋನಿನ ಕ್ಯಾಲೆಂಡರ್‌ಗೆ ದಿನನಿತ್ಯದ ನೆನಪು (.ics) ಮತ್ತು ವಾಟ್ಸಾಪ್‌ನಲ್ಲಿ ನಿಮಗೇ ಸಂದೇಶ. ಆ್ಯಪ್ ತಾನಾಗಿ ನೋಟಿಫಿಕೇಶನ್ ಕಳಿಸಲು ಸರ್ವರ್ ಬೇಕು — ಅದು ಮುಂದಿನ ಹಂತ.

## ಆವೃತ್ತಿ 2.1 ರಲ್ಲಿ ಏನು ಬದಲಾಯಿತು

- **ಹಂತ 4 — ಸರಳವ್ಯಾಕರಣಮ್** (10 ಪಾಠ): ಕ್ರಿಯಾಪದ (ಏಕ/ಬಹುವಚನ), ಲಿಂಗ, ವಚನ, ದ್ವಿತೀಯಾ, ಸಪ್ತಮೀ, ಷಷ್ಠೀ, ಪ್ರಶ್ನೆ, ಲೋಟ್, ಸಂಧಿ ಪರಿಚಯ. ಪ್ರತಿ ಪಾಠಕ್ಕೆ ವಿವರಣೆ, ಉದಾಹರಣೆ ಕೋಷ್ಟಕ, 5 ಪ್ರಶ್ನೆ. `src/content.js` → `GRAMMAR`.
- **ಹಂತ 5 — ಸುಭಾಷಿತಮ್** (12 ಶ್ಲೋಕ): ದೇವನಾಗರಿ + ಕನ್ನಡ ಲಿಪಿ + ಅರ್ಥ + ಪದಚ್ಛೇದ + ಮೂಲ. ಕಂಠಪಾಠ ಗುರುತು, ಹಂಚಿಕೆ, ಖಾಲಿ ತುಂಬುವ / ಸಾರ ಆರಿಸುವ ಅಭ್ಯಾಸ. ಮನೆ ಪುಟದಲ್ಲಿ "ಇಂದಿನ ಸುಭಾಷಿತ". `SUBHASHITAS`.
- **ಹಂತ 6 — ವಾಚನಮ್** (7 ಗದ್ಯ): ವಾಕ್ಯ ಒತ್ತಿದರೆ ಅರ್ಥ, ಹೊಸ ಪದಗಳ ಪಟ್ಟಿ, ಗ್ರಹಿಕೆಯ ಪ್ರಶ್ನೆಗಳು. `READINGS`.

## ಆವೃತ್ತಿ 2.0 ರಲ್ಲಿ ಏನು ಬದಲಾಯಿತು

- ಅರ್ಥಗಳು ಸಂಸ್ಕೃತದ ರಚನೆಗೆ ಹೊಂದುವಂತೆ ತಿದ್ದಲಾಗಿದೆ (ಉದಾ: `पठामि` = ಓದುತ್ತೇನೆ) — ವಿವರ `CONTENT_REVIEW.md` ನಲ್ಲಿ.
